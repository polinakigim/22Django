# Домашняя работа по Django
## Описание
Создание интернет-магазина на языке python с использованием фреймворка Django.
## Установка
- Устновить PyCharm
- Склонировать репозиторий
- Устновить Poetry, взяв зависимости из файла poetry.lock
## Фкнуционал
- manage.py - для запуска сервера и приложений
- config - настройки проекта Django
- catalog - первое приложение проекта, с двумя контроллерами и двумя страницами - home.html и contacts.htm
